# LeonDL — نسخهٔ ۲.۶.۱

**فارسی** | [English](README.md)

دانلودر دسکتاپی چندسرویسه و چندزبانه برای **yt-dlp**، ساخته‌شده با **PySide6 (Qt)**. به YouTube محدود نیست؛ لینک هر سرویسی که extractorهای نسخهٔ نصب‌شدهٔ yt-dlp پشتیبانی کنند را می‌پذیرد: YouTube، Instagram، TikTok، X/Twitter، Vimeo، Twitch، SoundCloud، Facebook، Reddit، Dailymotion و…

> مستندات کامل پروژه در مخزن قرار دارد — فایل‌های ریلیز فقط شامل README، VERSION و LICENSE هستند.

## امکانات اصلی

- **پیش‌نمایش هم‌زمان همهٔ لینک‌ها** با کارت مستقل (عنوان، سرویس، مدت، بندانگشتی، وضعیت)؛ خطای یک لینک بررسی بقیه را متوقف نمی‌کند
- **انتخاب کیفیت/فرمت**: خودکار، بهترین کیفیت، MP4، 8K تا 144p، MP3، M4A، صدای اصلی بدون تبدیل
- **انتخاب زبان صدا و زیرنویس** برای هر لینک (زیرنویس دستی و خودکار)
- **Queue / صف دانلود**: صف پایدار با دریافت متادیتا در پس‌زمینه (عنوان، مدت، اندازه، سرویس، زمان افزودن)؛ انتخابگر کیفیت/فرمت داخل هر سطر صف با محاسبهٔ زندهٔ حجم
- **پایش کلیپ‌بورد**: وقتی لینک دانلودی کپی می‌شود، به‌صورت خودکار شناسایی و به لیست لینک‌ها اضافه می‌شود (قابل خاموش‌کردن در تنظیمات)
- **پوشه‌بندی خودکار بر اساس سرویس**: `youtube.com/…`، `instagram.com/…`، `soundcloud.com/…` و… (قابل غیرفعال‌سازی)
- **احراز هویت محافظت‌شده**: کوکی مرورگر، کوکی دستی و پروفایل‌های ذخیره‌شدهٔ هر دامنه؛ رمزنگاری با DPAPI در Windows؛ به‌خاطر سپردن آخرین روش موفق هر سرویس
- **افزونهٔ Chrome (Manifest V3) + Native Messaging**: ارسال صفحه/لینک به Download یا Queue و ارسال اختیاری کوکی همان دامنه با اجازهٔ صریح کاربر
- **Package Manager**: بررسی محیط و نصب/به‌روزرسانی yt-dlp، FFmpeg، FFprobe، Deno و موتورهای اختیاری
- **موتورهای اختیاری**: `gallery-dl` (تصاویر/GIF Reddit و Instagram)، `spotDL` (متادیتای Spotify)، `apkeep` (دانلود APK اندروید از Google Play، APKPure، F-Droid و AppGallery)
- **رابط دوزبانهٔ فارسی (RTL) / انگلیسی (LTR)** با فونت Vazir
- **۵ تم**: Midnight Aurora، Golden Obsidian، Royal Navy، Ivory Light و YouTube Studio (پیش‌فرض)
- **نمودار سرعت زنده** (سبک Steam)، لاگ کناری، Splash Screen و رویدادهای صوتی قابل‌تنظیم (پک صدای CC0)

## پیش‌نیازها

- Python 3.10 یا جدیدتر + pip
- `yt-dlp[default,curl-cffi]` نسخهٔ 2026.06.09 یا جدیدتر (برای PornHub و سرویس‌های نیازمند browser impersonation)
- `yt-dlp-ejs` و `curl_cffi` (پشتیبانی JavaScript challenge)
- PySide6، FFmpeg، FFprobe، Deno

## نصب و اجرا در Windows

1. فایل ZIP را کامل Extract کنید.
2. روی `LeonDL.vbs` دوبار کلیک کنید — برنامه بدون نمایش پنجرهٔ CMD اجرا می‌شود.
3. در اولین اجرا، `.venv` و بسته‌های اصلی خودکار آماده می‌شوند؛ ابزارهای جانبی (FFmpeg و…) بعداً از بخش Packages and Tools نصب می‌شوند.

> **خروجی EXE ویندوز (پیشنهادی برای کاربر عادی):** فایل ZIP را Extract کنید و مستقیم `LeonDL-2.6.8.exe` را اجرا کنید — نیازی به اجرای سورس یا `.bat`/`.vbs` نیست. در اولین اجرا، EXE ابزارهای FFmpeg/FFprobe و Deno را چک و در صورت نبود، خودکار در پس‌زمینه نصب می‌کند.

ابزارهای جانبی:

| فایل | کاربرد |
|---|---|
| `setup_windows.bat` | آماده‌سازی دستی بسته‌های اصلی |
| `diagnose_windows.bat` | عیب‌یابی کامل محیط |
| `run_windows.bat` | فقط سازگاری قدیمی — همان لانچر مخفی را اجرا می‌کند |

لاگ‌ها در `leon_setup.log` و `leon_runtime.log` ذخیره می‌شوند.

## اجرای دستی از سورس

```bash
python bootstrap.py --skip-external
python app.py
```

## افزونهٔ Chrome

1. در برنامه وارد صفحهٔ «افزونه Chrome» شوید و **نصب / تعمیر اتصال** را بزنید (Native Messaging را برای حساب فعلی Windows ثبت می‌کند).
2. در Chrome آدرس `chrome://extensions` را باز کنید، **Developer mode** را فعال و **Load unpacked** را بزنید.
3. پوشهٔ نمایش‌داده‌شده در برنامه را انتخاب کنید.
4. کد Pairing را از برنامه کپی و یک‌بار در Popup افزونه وارد کنید.

سپس در دسترس است:

- **Send to Leon** — ارسال URL صفحه به Download و اجرای خودکار Preview
- **Add to Queue** — افزودن مستقیم به صف (دکمه یا راست‌کلیک)
- **Send site cookies** — فقط با اجازهٔ صریح کاربر، محدود به دامنهٔ همان صفحه؛ کوکی‌های Partitioned یا نامرتبط پذیرفته نمی‌شوند

## ساخت EXE در Windows

```text
BUILD-EXE.bat
```

خروجی PyInstaller در پوشهٔ `dist` ساخته می‌شود. ساخت واقعی EXE باید روی Windows انجام شود.
