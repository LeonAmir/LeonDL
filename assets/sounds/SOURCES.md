# LeonDL sound sources

LeonDL's default `Gentle & pleasant` sound pack uses existing sounds
from Wikimedia Commons. The audio is downloaded lazily by the application and
cached under the user's Leon configuration directory; the repository does not
redistribute generated substitute tones.

All four selected source files are published under the Creative Commons CC0
1.0 Universal Public Domain Dedication on their Wikimedia Commons description
pages.

| Leon use | Source file | Source page | License |
| --- | --- | --- | --- |
| Download complete / notification | `Simple Happy Beep.ogg` by waveplaySFX | https://commons.wikimedia.org/wiki/File:Simple_Happy_Beep.ogg | CC0 1.0 |
| Queue complete | `Sucesso.ogg` by Rafael Tavares Juliani | https://commons.wikimedia.org/wiki/File:Sucesso.ogg | CC0 1.0 |
| Warning | `Airplane Chime Sound Effect.ogg` by Sharelk | https://commons.wikimedia.org/wiki/File:Airplane_Chime_Sound_Effect.ogg | CC0 1.0 |
| Cancel / error | `Tone.c.ogg` by Bautsch | https://commons.wikimedia.org/wiki/File:Tone.c.ogg | CC0 1.0 |

The user may override every event with a local WAV, OGG/OGA, MP3, M4A, AAC, or
FLAC file from Settings. Source licenses for user-provided files remain the
user's responsibility.
